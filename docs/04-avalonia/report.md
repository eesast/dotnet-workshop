## 功能实现


图形界面客户端 LogAnalyzerClient 的如下功能（T4.1）：

1. 刷新文件列表（Refresh）：调用 `GetLogFiles` RPC 获取服务器当前目录的日志文件，清空并重建 `LogFiles` 集合，界面列表自动刷新。菜

2. 分析选中的文件（Selected）：Ctrl 多选文件后点击 Selected，调用 `AnalyzeFiles` RPC，请求中带上并行度和选中的文件名列表；并行度会先做整数校验。

3. 分析全部文件（All）：在 Analyze 栏新增 All 按钮（axaml 加第五列），绑定新写的`AnalyzeAllCommand`，调用 `AnalyzeAll` RPC。

4. 分析右键选中的文件（Analyze File）：右键菜单触发 `AnalyzeRightClickedFileCommand`，分析当前选中的单个文件。

5. 查看分析结果（View Analysis Results）：右键菜单触发，使用流式 RPC `GetAnalysisResult`
